## 4. 工程架构速览

这是 Kotlin Multiplatform + Compose Multiplatform 工程：

- `apps/multiplatform/android`：Android Application、Activity、Service、Manifest。
- `apps/multiplatform/common`：Android/Desktop 共享 Compose UI、状态、API 和资源。
- `apps/multiplatform/desktop`：Desktop 壳。

主启动链：

```text
SimplexApp.onCreate()
  → MainActivity.onCreate()
  → setContent { AppScreen() }
  → MainScreen() root state gates
  → AndroidScreen()
  → ChatModel / ChatController
  → Core.kt JNI
  → libsimplex / Haskell core
```

关键文件：

- `apps/multiplatform/android/src/main/java/chat/simplex/app/SimplexApp.kt`
- `apps/multiplatform/android/src/main/java/chat/simplex/app/MainActivity.kt`
- `apps/multiplatform/common/src/commonMain/kotlin/chat/simplex/common/App.kt`
- `apps/multiplatform/common/src/commonMain/kotlin/chat/simplex/common/model/ChatModel.kt`
- `apps/multiplatform/common/src/commonMain/kotlin/chat/simplex/common/model/SimpleXAPI.kt`
- `apps/multiplatform/common/src/commonMain/kotlin/chat/simplex/common/platform/Core.kt`
- `apps/multiplatform/spec/architecture.md`

重要约束：

- `commonMain` 不是 Android 私有代码；修改会影响 Desktop。
- 根状态门中迁移、数据库、初始化、欢迎、锁屏等顺序不能随意改变。
- 当前主题使用 Compose Material 2 API。首版建立 Nome token/组件并实现 Material 3 风格行为，不做整库 Material 3 迁移。
- UI 只换壳和交互编排，核心状态继续来自现有 model/controller。

