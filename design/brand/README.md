# Nome Brand Assets

This folder contains the approved Nome logo direction for the project.

## Canonical Files

- `nome-logo.png` - primary horizontal logo for docs, website, and product surfaces.
- `nome-app-icon.png` - source app icon crop from the approved brand sheet.
- `nome-app-icon-1024.png` - app icon export size for store/icon pipelines.
- `nome-app-icon-512.png`, `nome-app-icon-256.png`, `nome-app-icon-128.png`, `nome-app-icon-64.png` - preview and implementation sizes.
- `nome-mark.png` - standalone brand mark.
- `nome-lockup-dark.png` - dark background lockup.
- `nome-logo-mono.png` - one-color navy lockup.
- `nome-logo-assets-sheet.png` - full approved presentation sheet with the selected bold wordmark.
- `nome-logo-assets-sheet-bold-backup.png` - backup copy of the selected bold wordmark version.
- `nome-logo-assets-sheet-medium-backup.png` - lighter wordmark exploration, kept for comparison.

## Palette

- Deep navy: `#0E1B2D`
- Privacy green: `#16AE66`
- Trust blue accent: `#276BFF`

## Notes

Use `Nome` exactly as written: capital `N`, lowercase `ome`.
Do not use `NoMe`, `SimpleX`, or mixed casing in branded surfaces.
The approved wordmark direction is the bolder version from the selected asset sheet.
